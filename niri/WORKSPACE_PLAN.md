# niri 工作区分配（科研 / 多窗口）

> 目标：把“检索-阅读-写作-实验-沟通”拆开，减少窗口来回切换。

## 推荐分配

1. **收件箱 / 启动区**
   - 临时窗口、下载页、一次性任务。
2. **浏览器检索（Vivaldi）**
   - 文献检索、Wiki、官方文档、搜索结果。
3. **论文阅读（Papers）**
   - PDF 深度阅读、批注、对照阅读。
4. **文件与素材（Nautilus）**
   - 数据集、附件、图片、实验输出整理。
5. **写作与笔记**
   - 论文草稿、实验记录、会议笔记。
6. **终端 / 实验（foot）**
   - 训练、脚本、日志、远程会话。
7. **通信与日程**
   - IM、邮件、会议网页。
8. **账号与安全（1Password）**
   - 登录、双因子、敏感操作确认。
9. **演示 / 备用**
   - 开会分享、投屏、临时演示窗口。

## 对应按键

- 切换工作区：`Mod + 1..9`
- 移动当前列到工作区：`Mod + Ctrl + 1..9`
- 常用应用：
  - 启动器：`Mod + Space`
  - `foot`：`Mod + Return`
  - `Nautilus`：`Mod + E`
  - `Papers`：`Mod + P`
  - `Vivaldi`：`Mod + B`
  - `1Password`：`Mod + O`
